## 这是什么

一套面向公务员 / 事业单位行测「言语理解与表达」的 AI Skill。不是知识点罗列，而是一条决策流水线：

**文段类型 → 行文结构 → 盯住的信息 → 正确项长什么样 / 错误项怎么造出来的**

覆盖 15 张能力卡：

| 模块 | 能力 |
|---|---|
| 片段阅读 | 判文段类型、说理类找主旨、五类对策信号、对策核心做法、四类错误选项、科普类概括、科普四大类、新闻类抓"新"、标题拟定、下文推断、语句填入、语句排序、细节判断 |
| 逻辑填空 | 六种逻辑对应、词义辨析五维 |

### 方式一：手动复制（通用，推荐）

把 `huasheng13-yanyu` 整个文件夹放进你的技能目录：

```text

~/.workbuddy/skills/huasheng13-yanyu/SKILL.md

# Windows
C:\Users\<你的用户名>\.workbuddy\skills\huasheng13-yanyu\SKILL.md
```

> 注意不要多套一层目录。放好后路径应当**直接**指向 `skills/huasheng13-yanyu/SKILL.md`。

## 怎么问才好用

**最适合的三类问法：**

1. **带完整题目问** —— 贴题干 + 四个选项，问"这题选什么，为什么其他三个不行"。它会逐项给排除理由，而不是只报答案。
2. **问二选一** —— "我觉得是 B，答案是 C，区别在哪"。这类问题它答得最好，因为可以直接对比两个选项的设错方式。
3. **问某类题怎么做** —— "语句排序怎么找首句""科普类怎么概括"，给的是可执行判据，不是泛泛方法论。

**不适合的：**

- 时政观点、申论写作（不在范围内）
- 单个成语的词典释义（直接查词典更快）
- 数量关系、判断推理、资料分析（不属于言语理解）

## 来源与边界

**来源**：整理自花生十三 2026 言语理解系统课（片段阅读 6 讲 + 逻辑填空 2 讲 + 加课/总结 3 讲，共 12 个视频、约 21.5 小时），并结合随堂讲义与课件校对术语。

**仅供个人学习交流，请勿用于商业用途或二次售卖。** 建议配合原课程视频一起使用——这个包是索引和判据表，替代不了听课。

**它做不到的事**（原作者讲课时自己承认的软肋）：

- 这套方法**假设每道题都有唯一主旨句**。科普并列类经常没有，只能靠"概括全面 + 找上位词"补，但"全面到什么程度"仍然靠语感。
- **判类是前置条件**，判错类型后面全错。所以它回答时会先说"我判断这是 X 类"，你可以直接纠正它再往下走。
- 逻辑填空的辨析维度覆盖高频易混词，但覆盖不了全部约 1000 词，冷僻词仍要靠积累。
