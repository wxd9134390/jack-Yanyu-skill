# 决策规则速查 — 花生十三 · 言语理解

| 能力 | 一句话规则 |
|---|---|
| 三型判别：先定文段类型 | 先判说理/科普/新闻，再谈结构；类型决定你盯句子、盯词还是盯"新"。 |
| 说理类：主旨句定位 | 说理类全文只服务一句话，主旨句只在文首（前对策）或文末（后对策）。 |
| 五类对策信号与"对策翻译" | 对策不止"应该"——祈使/禁止/逻辑关联词/必要条件/语义隐含，任一中即为对策句。 |
| 主体—目标—对策核心做法 | 把对策句切成"谁/为了什么/怎么做"，选项必须复现"怎么做"那一截动宾短语。 |
| 选项分析：四类错误与逆推、双标 | 错项可穷举——出处有误、客观表达、拼好句、无核心做法；再用逆推与双标收尾。 |
| 科普类：概括全面（并列/上位词/合并同类项） | 科普抓全不抓句——高频词 + 合并同类项 + 允许用上位词，片面即错。 |
| 科普四大类的双向用法 | 原因/具体/历程/区别比较联系，既是文段结构也是选项模板，可双向反推。 |
| 新闻类：抓"新"且要具体 | 新闻只看一个字"新"，新做法要具体，专名不许换成上位概念。 |
| 标题拟定：主旨变形 + 文体调性 | 标题＝先按三型取主旨，再按文体改造：说理加力量感、科普补主体+主题、新闻点名新举措。 |
| 下文推断：七种结构续写 | 下文推断是把被切开的两段接回去——七种结构定方向，四条硬排除定答案。 |
| 语句填入：给二求一 + 四抓手 | 先当片段阅读判断"这句该干什么活"（问题/对策/论证给二补一），再当逻辑填空用四抓手锁死。 |
| 语句排序：套结构 + 抓捆绑 | 先套文段结构定句子区位，再用同词/指代/首尾把句子两两绑死，两层都过才选。 |
| 细节判断：切块定位 + 偷换清单 + 择优 | 十秒切块建地图，逐项定位，按七类偷换核，两项都有病时抓大放小。 |
| 逻辑填空：六种逻辑对应 | 横线处由原文某处管着——成语拆分/因果/比喻/近反义/褒贬/用词一致，六条线索定方向。 |
| 词义辨析：五维与"重复"判据 | 近义词只在对象/侧重/程度/结构/语境五维上有差别；语义重复不是病，字词重复才是病。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
