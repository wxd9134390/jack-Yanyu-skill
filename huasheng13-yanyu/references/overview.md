## 1. 结构 (Structural)

### 类型

应试方法论 / 解题决策框架（不是知识点罗列，而是"看什么→怎么判断→选哪个"的决策流水线）

### 一句话主旨

**先判断这段文字属于哪一类文段，文段类型决定它常见的行文结构，行文结构决定你要盯住哪一处信息，那一处信息又决定正确选项长什么样、出题人会把错误选项造成什么样。**

整套课程只有这一条主线，其余全部是这条主线在六种题型上的具体化。

### 骨架（主要论点及其关系）

1. **三类文段**：说理类（作者有观点/对策）、科普介绍类（客观介绍事物/知识）、新闻类（新事件/新突破）。
2. **行文结构由类型决定**：说理类＝前对策 / 后对策；科普类＝总分 / 分总 / 并列与大并列；新闻类＝背景+新 / 新+分析 / 过去+新变化。
3. **关注点由结构决定**：说理类盯"对策句/主旨句"（句子级）；科普类盯"概括词+高频词"（词语级，需自己合并同类项）；新闻类只盯一个"新"字。
4. **选项设置由关注点决定**：每一类文段都有一套"正确选项特征 + 三类高频错误选项"，可以反过来用出题人视角排除。
5. **五类对策信号 + 五种引出话题方式**：用于在说理类文段里快速定位对策句；五种引出方式本身就是四种特殊科普结构的来源。
6. **六种题型共用同一套判断**：中心理解、标题拟定、下文推断、语句填入、语句排序、细节判断，都是把上面的结构套一遍，只是"要填/要排的是哪一块"不同。
7. **逻辑填空是同一逻辑的微观版**：横线前后找"逻辑对应"（六种对应关系），再用词义辨析（1000 词）落地。

**论点之间的关系**：层层递进（一条因果链），并在第 6、7 点分叉到不同题型。这是本课区别于其他机构"题型技巧拼盘"的关键。

### 作者要解决的核心问题

学员做言语题的三个真实病灶：
- 读文段没有抓手，"读完不知道哪句重要"→ 用"文段类型→结构→关注点"给出确定位置；
- 找到主旨句仍选错，"看着都对"→ 把正确选项拆成"目标 + 对策核心做法"，把错误选项拆成四类可命名陷阱；
- 凭语感做逻辑填空 → 用"逻辑对应"把语感变成可核对的线索。

## 2. 解释 (Interpretive)

### 关键术语（作者本人的用法）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 文段类型 | 说理 / 科普介绍 / 新闻 三类，由"作者想干什么"定，不由题材定 | 常识按"政治/经济/科技"分题材，这里按写作意图分 |
| 前对策 / 后对策 | 先给对策再论证 / 先论证末尾给对策 | 不是"总分总"这类修辞概念，是"主旨句在第几句" |
| 对策的核心做法 | 对策句里那个具体动作（如"引入律师团队"里的"引入律师"） | 常识把整句当对策，这里只认那个不可替换的动作 |
| 目标 | 对策要解决的问题 / 要达到的状态（"想考上公务员"） | 与"主体"（写给谁）严格区分：主体是人，主题是事 |
| 主体 / 主题 | 主体＝谈论对象（如"专精特新企业"）；主题＝谈论的事 | 很多老师混用，作者明确二分 |
| 拼好句（拼多多选项） | 从各句各抓两个词拼成的"看似全面"选项 | 常识以为"概括全面"更好，作者认为说理类恰恰要"抓重点不要全面" |
| 出处有误 | 选项信息取自分析/论据/背景部分，不是主旨句 | 不是"与原文不符"，而是"来源层级不对" |
| 上位词 | 科普类并列结构中，原文没有但能概括全篇的词（如"社会变迁"） | 常识认为选项必须用原文词，作者明确"双标"：说理类必须用原文，科普并列类可用上位词 |
| 四大类 | 因果 / 历程 / 具体 / 区别比较联系，既是文段结构也是选项类型 | 不是四种题型，是"看到这种选项就反推原文该长什么样" |
| 傻瓜式对策 | 由问题直接反推的最小对策（"不重视行测"→"要重视行测"） | 不等于自己加戏的细化建议（"多花时间报个班"＝对策的对策，错） |
| 双标 | 不同类型的文段用不同标准评判选项，不追求统一标准 | 与"一招通吃"的应试套路相反 |
| 33555 / 264111 | 老版口诀：3 类文段、3 个关注点、5 种结构、5 种对策、5 种引题；2 种出处有误、6 类选项、4 大类 | 新版把它重排为"类型→结构→关注点→选项"的因果链 |

### 核心命题（用自己的话）

1. 言语题不是"读懂了就会"，而是"知道该盯哪儿"——信息的重要性由结构决定，不由内容决定。
2. 每个文段只有一个"结算点"：说理类是一句主旨句，科普并列类是一组高频概括词，新闻类是一个"新"。
3. 正确选项可以用三层标准排序：目标+对策做法俱全 > 纯对策/纯概括 > 宽泛对策；有对策的宽泛选项仍优于无对策的精确选项。
4. 错误选项是可穷举的：出处有误、客观表述、拼好句、宽泛/片面/主观越位。
5. 找对策靠五种语言信号（祈使、禁止、逻辑关联词、必要条件、语义隐含），找主旨靠首句定主体/主题 + 尾句收口。
6. 六种题型不增加新知识，只改变"你要产出的是哪一块"：标题＝主旨变形＋力量感/趣味性；下文推断＝结构续写；语句填入＝缺块反推；语句排序＝结构复位＋捆绑；细节判断＝逐项比对。
7. 逻辑填空＝在句子内部做同一件事：先找逻辑对应（成语拆分/因果/比喻/近反义/褒贬/用词一致），再词义辨析。

### 论证链

作者用"出题人视角"反向论证：既然正确答案只能从主旨句出，那么错误选项就只能从非主旨句出（出处有误）、或去掉主观性（客观表述）、或把非主旨句拼起来（拼好句）。这条推理把"选项分析"从经验判断变成了结构推导，也是本课与"语感派"的分水岭。

## 3. 批判 (Critical) ★

### 作者的时代局限

- 例题以 2020—2026 国考/省考/事业单位为主，方法对"结构清晰的老题型"最有效；对近年出现的"多观点并列、无明显对策"的新式文段，作者靠"双标"和"哪个更致命"的经验兜底，规则化程度下降。
- 33555 老口诀与新版因果链并存，课程内两套语言混用，初学者容易记混（作者自己在加课里承认"今年更细化了"）。

### 作者的立场盲点

- 强假设"每道题都有一个唯一主旨句"。科普并列类其实常常没有，作者用"概括全面 + 上位词"补，但"全面"到什么程度算够，仍靠语感。
- "对策宽泛也优于无对策"这条在选项质量都差时会失效，作者用"哪个有更致命的问题"收尾，属经验判断。
- 逻辑填空高度依赖 1000 词积累，方法只能解决"对应"，解决不了"不认识这个词"，作者对此只说"交给 1000 词"。

### 未被证明的假设

- 假设出题人稳定按"四类错误选项"出题。实际存在"两个选项都合理、靠出题人偏好定答案"的题（作者也承认"言语是主观的事"）。
- 假设"主体/主题/目标/对策做法"可以清晰切分，实际长选项里四者常粘连。

### 最强反对意见

> 这套方法把"理解"压缩成了"定位"，遇到结构反常（无主旨句、多主旨、反讽、学术转述）的文段会系统性失效；而且它需要先正确判类，判类一错，后面四步全错，误差被放大而非收敛。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**

## 4. 应用潜力 (Applicability)

### 可 skill 化的内容

- [x] 判类：三步定文段类型（说理/科普/新闻）
- [x] 说理类：前后对策识别 + 主旨句定位 + 目标/对策核心做法
- [x] 五类对策信号词表（祈使/禁止/逻辑关联词/必要条件/语义隐含）
- [x] 五种引出话题方式（含"由大引小"识别例子的陷阱）
- [x] 科普类：并列/大并列的"概括全面 + 合并同类项 + 上位词"
- [x] 科普四大类（因果/历程/具体/区别比较联系）的双向用法：看文段定选项、看选项反推文段
- [x] 新闻类：抓"新"
- [x] 选项分析：正确选项三层排序 + 四类错误选项命名
- [x] 标题拟定：主旨变形 + 力量感/趣味性/新颖度
- [x] 下文推断：七种结构续写 + "不能写什么"
- [x] 语句填入：缺块反推（给二推一）+ 承上启下 + 句式/指代/搭配
- [x] 语句排序：结构复位 + 首尾句/捆绑/时间轴/分堆
- [x] 细节判断：逐项比对与偷换类型
- [x] 逻辑填空：六种逻辑对应 + 词义辨析

### 不适合 skill 化的内容

- 1000 词的具体词义（属记忆材料，保留为词表引用，不独立成 skill）
- 单题逐题讲解（保留为 A1 案例素材）
- 课堂闲聊、机构对比、学员答疑（无方法论价值）

### 预估 skill 数量

**约 12–14 个候选单元**，经三重验证后预计 8–10 个；晋级为独立 Skill 的预计 3–5 个（其余作为来源路由入口内的能力卡）。

### 优先级排序（按"最能赋能考生"的角度）

1. 判类（一切的前提）
2. 说理类主旨句定位 + 目标/对策核心做法
3. 选项分析（四类错误选项 + 三层正确选项）
4. 科普类概括（并列/上位词/四大类）
5. 逻辑填空六种对应
6. 三个小题型（标题/下文/填入/排序）
7. 细节判断
