## R — 原文

> "涉及因材施教和因势利导的辨析，因势对应'重视孩子自身的兴趣'，利导对应'切实发挥后天培养的作用'，而因材施教侧重多个孩子区别对待、差异化教育，无法对应原文。"（逻辑填空第一讲 §12.1 例题 3 解析）

> "量入为出：衡量自己的能力或实际情况去做事；精打细算：资源不多时精细地打算。"（同上 例题 5 解析）

## I — 自述

近义词的差别几乎只落在五个维度上，把这五维当尺子，二选一就变成可回答的问题：

- **对象**：谁来做、对谁做（因材施教针对"多个孩子",因势利导针对"一个孩子的特点"）。
- **侧重**：强调哪一面（量入为出强调"按能力定支出"，精打细算强调"把有限资源算细"）。
- **程度**：轻重（卷土重来是失败后积蓄力量反扑，程度轻；死灰复燃是刚要灭又活，程度重）。
- **结构**：词性与搭配（"难以问津"要能带"探求"义，"难以为继"要能带"继续"义）。
- **语境**：惯常出现在哪类场景（"按部就班"用于既定步骤，"循序渐进"用于由浅入深）。

背词要背三层：字面义（每个字什么意思）→ 引申/比喻义 → 适用语境。只记整体大意，遇到拆分题与辨析题就废。

另外一条纠偏：**"重复"不是病**。用词重复（"令人贻笑大方"）才是病；语义复现是成语拆分的原理，不能拿它当排除理由。

## A1 — 书中案例

1. **因材施教 vs 因势利导**（2025 重庆选调）：原文"重视孩子自身的兴趣……发挥后天培养的作用"——"因势"对兴趣，"利导"对后天培养；因材施教侧重多个孩子差异化，对象不合，排除。答案 D「迷信 因势利导」。
2. **量入为出 vs 精打细算 / 细水长流 vs 勤俭持家**（2023 内蒙古）：原文"建立在已有经济基础之上"，是按能力定支出 → 量入为出；"把日子过好"要长久 → 细水长流，而非夸某人会持家。答案 A。
3. **卷土重来 vs 死灰复燃**（2023 事业单位·山寨食品）：原文"春风吹又生"，是刚要灭又活，程度重 → 死灰复燃更贴；卷土重来是失败方蓄力反扑。
4. **走马观花类四兄弟**（同上）：走马观花（过程不细）、敷衍了事（责任心差）、视若无睹（不理睬）、小打小闹（规模小）——按"侧重"分槽，原文"没时间精力深入检查"落在"过程不细"。

## A2 — 未来触发

- **场景**：逻辑对应已经找到，但剩两个近义词；或用户在背/辨析一组词，问"这两个到底差在哪"。
- **语言信号**："这两个词有什么区别""因材施教和因势利导怎么分""为什么不能选这个成语""近义词辨析"。
- **与相邻能力区分**：找线索定方向 → 逻辑填空六种对应；本卡只在"方向已定、词还没定"时启用。

## E — 执行步骤

1. 写出两个候选词的字面义（逐字）。**完成标准**：每个字都能说出意思。
2. 依次比对五维：对象 → 侧重 → 程度 → 结构 → 语境。**完成标准**：至少找到一维明确不同。
3. 把这个差异与原文的"管辖句"对齐。**完成标准**：能说出"原文要的是 A 维的哪一侧"。
4. 检查搭配：把词代回原句，看动宾/主谓是否成立。**完成标准**：无搭配硬伤。
5. 不要用"语义重复"排除。**完成标准**：确认排除理由落在五维上。

## B — 边界

- **五维不是万能的**：有些词差别在感情强度或语体（书面/口语），需另行积累。
- **不要用"哪个更文雅"选**：语体只在原文语体明显时才作依据。
- **词义辨析解决不了"不认识"**：不认识就回到语境猜义，或承认此题放弃（考场策略）。
- **本卡不适用于整句填入**，那是句式与结构问题。
