# 言语理解 · 术语词典

> 按花生十三的用法定义，并标注与通行/常识用法的差异。凡"作者的定义"一栏，都是本课内部的严格口径。

## 一、结构与类型

| 术语 | 作者的定义 | 与常识用法的差异 |
|---|---|---|
| 文段类型 | 说理类 / 科普介绍类 / 新闻类，按"作者想干什么"分 | 不按题材（政治/科技/经济）分；题材相同也可能属不同类型 |
| 说理类 | 传递作者观点或对策，目的是让你认同或照做 | 不等于"议论性文字"；说明文里出现"应当"也可能是说理 |
| 科普介绍类 | 客观介绍事物、现象、知识，无立场 | 包括"辟谣"类（"没那么神"是把科普讲清楚，不是主张） |
| 新闻类 | 围绕新近事件、新突破、新进展 | 新闻评论属说理类，不属新闻类 |
| 前对策 | 引出话题后直接给对策/观点，后文论证 | 也叫"开门见山"；不叫"总分总" |
| 后对策 | 先引入、分析、论证，末尾给对策/观点 | 也叫"娓娓道来"；是中心理解题最常见结构 |
| 总分 / 分总 | 总括句在前 / 在后 | 在说理类里，总分＝前对策，分总＝后对策，只是叫法不同 |
| 并列 / 大并列 | 分论点地位相当、无主次（两个或三个以上） | 与"并列短语"无关；重点靠归并，不靠某一句 |
| 特殊并列 | 科普类中带二层结构的并列：转折、背景+正文、设问+回答、由大引小 | 名为并列，实有主次，重点位置各不相同 |
| 二层结构 | 老口诀里的"第二层结构"，现全部下放为科普的特殊并列 | 不是独立第五种结构 |
| 由大引小 | 先给集合、再讲集合中的某个个体（像三段论） | 不是总分；总分是概括与举例，它是范围收缩，小段可能是主体 |

## 二、判据与选项

| 术语 | 作者的定义 | 与常识用法的差异 |
|---|---|---|
| 主体 | 谁的事儿：人、机构、产业、事物 | 不等于主题词；主体是施事者，可缺失 |
| 主题 | 说的是什么事儿（问题、目标、对象） | 常被误当"中心思想"；此处只指话题内容，不含态度 |
| 目标 | 对策要解决的问题 / 要达到的状态 | 与"主题"不同：目标是"想要 X"里的 X |
| 对策的核心做法 | 对策里真正可操作的那一步动宾短语（"要努力"） | 不等于整句对策；目标是虚的，做法才是硬的 |
| 对策翻译 | 把任何对策句统一改写成"想要 X，需要 Y" | 不是翻译外语，是统一句式便于比选项 |
| 傻瓜式对策 | 由问题直接反推的最小对策（"不重视行测"→"要重视行测"） | 不等于自己加戏的细化建议（"多报个班"＝对策的对策） |
| 对策的对策 | 在原文对策之上再推一步的更细对策 | 属越界项，通常错 |
| 出处有误 | 选项信息取自分析、论据、例子、背景、转折前、"因此"前、被指代处 | 不是"原文没有"，而是"原文有但位置不重要" |
| 客观表达 | 只陈述现象、不含态度与做法的选项 | 科普类的正确答案形态，说理类的硬伤 |
| 拼好句（拼多多选项） | 从各句各摘词拼成的"看似全面"选项 | 听着像概括全面，实为无主旨的碎片拼接 |
| 上位词 | 原文未出现、但能概括全篇的概念（如"社会变迁"） | 打破"必须原文原词"的通行教条；仅科普并列类可用 |
| 合并同类项 | 把同义的分论点归并为一个表述 | 不是简单罗列；是"全面"的实现手段 |
| 双标 | 标准随文段类型与选项竞争格局变化；对高概率正确项主动找理由 | 不是道德意义上的双重标准，是技术动作 |
| 一正确 / 一验证 / 一比较 | A且B形式正确率高 / 选项逆推原文 / 具体优于宽泛 | 老口诀"264111"里的三个 1 |
| 四大类 | 原因、具体、历程、区别比较联系 | 既是文段结构也是选项模板，**不是错误类型** |
| 特殊科普类 | 科普外壳但介绍的是对策或问题（老师亦称"科普对策/科普问题"） | 需同时满足"概括全面"与"体现对策/问题"两套要求 |

## 三、题型与操作

| 术语 | 作者的定义 | 与常识用法的差异 |
|---|---|---|
| 给二求一 | 语句填空中，问题/对策/论证三块给两块、补第三块 | 不是"看哪个读着顺" |
| 承上启下句 | 前半截回指上文话题、后半截引出下文话题的过渡句 | 只照顾一边的叫"偏心眼儿"，不合格 |
| 分堆 | 排序题里按话题把句子切成前后两半 | 切口是同时含两个话题的"双话题句" |
| 定序信号 | 时间轴、先介绍后引用、总分抓总句 | 出现任一即可排，不必读懂内容 |
| 十秒扫块 | 细节判断先按句号切块、只建"第几块讲什么"的地图 | 不是通读理解，是建索引 |
| 抓大放小 | 先判大方向是否荒谬，再查虚词细节 | 不是粗心，是有优先级的排查顺序 |
| 瑕疵题择优 | 两项都有病时，淘汰"违背常识/逻辑"的，保留"无中生有但符合常识"的 | 为拿分服务，不为严谨服务 |
| 逻辑对应 | 横线处由原文某处管着，六条线索可定位 | 不是语感；是可指认的对应关系 |
| 成语拆分 | 成语是作者把前文白话"再说一遍"，可逐语素反向还原 | 与"望文生义"相反：拆分必须回原文找配对的词 |
| 用词一致 | 作者围绕核心词反复回扣，横线常与之共用同一个字 | 同字只是线索，须"同字+语义+结构"三关齐过 |
| 语义重复 | 意思重复（正常）/ 字词重复（病） | 通行做法把"语义重复"当排除理由，本课明确否定 |

## 四、口诀

| 口诀 | 含义 | 在新体系中的位置 |
|---|---|---|
| 33555 | 3 类文段、3 个关注点、5 种结构、5 种对策、5 种引题 | 被拆解挂载到"类型→结构→关注点→选项"四段链 |
| 264111 | 2 种出处有误、6 类选项毛病、1 正确 / 1 验证 / 1 比较 | 落在选项分析卡 |
| 三正四特 | 科普的正结构三种（总分/分总/并列）+ 特殊并列四种 | 落在科普概括卡 |
